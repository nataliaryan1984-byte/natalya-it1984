# Xena: Warrior Princess — Fan Tribute

An independent, English-language, responsive static fan site about the fantasy television series **Xena: Warrior Princess**.

## Features
- Cinematic landing page and story introduction
- Character profiles: Xena, Gabrielle, Ares, Callisto
- Interactive tabs for all six seasons
- Series facts and a legacy section
- Mobile navigation, accessible HTML labels, reduced-motion support
- No build tools required

## Run locally
Open `index.html` in a browser.

## GitHub Pages
In the parent repository, choose **Settings → Pages → Deploy from a branch → main / root**. The site will then be at `https://nataliaryan1984-byte.github.io/natalya-it1984/xena-warrior-princess/`. This is an expected address, not a verified live URL.
